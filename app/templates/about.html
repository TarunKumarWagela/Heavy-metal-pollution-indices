Project Overview

HMPIAS is a scientific web application for assessing heavy-metal contamination in Indian groundwater using scientifically documented pollution indices, machine learning, geographical visualization, and downloadable reports.

Scientific Indices Implemented
  • HPI — Heavy Metal Pollution Index (Mohan et al., 1996)
  • HEI — Heavy Metal Evaluation Index (Edet & Offiong, 2002)
  • Cd Index — Degree of Contamination (Backman et al., 1998)
  • CF, PLI, Igeo — Soil/Sediment indices (Tomlinson et al., 1980; Müller, 1969)
Standards Used
  • BIS IS 10500:2012 (Amendment 2019) — Indian drinking water standard
  • WHO GDWQ 4th ed. + addenda (2022) — International guideline
Data Source

Primary data source: CGWB / National Water Data Portal

⚠ Disclaimer: Classification thresholds are literature-based and do not constitute regulatory determinations. BDL values are never silently set to zero. All calculation results record the standard version used.
